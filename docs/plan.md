# 📋 제로톤 기획 문서 ([plan.md](http://plan.md/))

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| **프로젝트명** | **푸드네이터 (Food-nator)** |
| **한줄 소개** | 10문장 내외의 질문으로 오늘 당신이 먹고 싶은 한국 음식을 맞히는 AI 아키네이터 |
| **Pain Point** | "오늘 뭐 먹지?"라는 결정 장애로 인해 메뉴 선택에 너무 많은 시간과 에너지를 소비하는 현대인 |

## 2. 타겟 사용자

- **주요 타겟**: 메뉴 결정권이 있지만 선택이 어려운 직장인 및 학생
- **사용자 특성**: 인터랙티브한 재미를 추구하며, 빠른 의사결정 보조 도구가 필요한 사람
- **시장 규모**: 배달 앱 사용자 및 외식 빈도가 높은 2040 세대 전체

## 3. MVP 범위 (2시간 내 구현)

### ❓ 질문 리스트 (총 10단계)

1. **Q1**: 지금 배가 몹시 고파서 든든한 '밥'이 먹고 싶나요? (예/아니오)
2. **Q2**: 따끈한 '국물'이 있는 요리를 원하시나요? (예/아니오/상관없음)
3. **Q3**: 오늘 스트레스를 받아서 '매운맛'이 당기나요? (매우/조금/전혀)
4. **Q4**: 주재료로 '육류(돼지, 소, 닭)'가 들어갔으면 좋겠나요? (예/아니오)
5. **Q5**: 음식이 시원하거나 '차가운' 종류여도 괜찮나요? (예/아니오)
6. **Q6**: 요리 방식은 어떤 게 좋은가요? (구이/찜·탕/볶음/기타)
7. **Q7**: 후루룩 먹기 좋은 '면 요리'를 좋아하시나요? (좋음/싫음)
8. **Q8**: 오늘 예산은 넉넉한 편인가요? (만원 이하/만원 이상)
9. **Q9**: 지금 분위기는 어떤가요? (혼자 빠르게/여럿이 시끌벅적)
10. **Q10**: 지금 당장 생각나는 느낌은? (고소함/칼칼함/담백함/기름짐/신선함)
