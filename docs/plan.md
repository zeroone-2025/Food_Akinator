# 📋 제로톤 기획 문서

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| **프로젝트명** | **푸드네이터 (Food-nator)** |
| **한줄 소개** | 11개의 질문으로 오늘 당신이 먹고 싶은 음식을 맞히는 AI 아키네이터 |
| **Pain Point** | "오늘 뭐 먹지?"라는 결정 장애로 인해 메뉴 선택에 너무 많은 시간과 에너지를 소비하는 현대인 |

## 2. 타겟 사용자

- **주요 타겟**: 메뉴 결정권이 있지만 선택이 어려운 직장인 및 학생
- **사용자 특성**: 인터랙티브한 재미를 추구하며, 빠른 의사결정 보조 도구가 필요한 사람
- **시장 규모**: 배달 앱 사용자 및 외식 빈도가 높은 2040 세대 전체

## 3. MVP 범위 (2시간 내 구현)

- [x] **핵심 기능 1**: 45종 한식·일식·중식 DB + 필터링 로직
- [x] **핵심 기능 2**: 가변형 질문 UI (선택지 1~5개)
- [x] **핵심 기능 3**: 11단계 질문 종료 후 최종 음식 추천 및 Early Exit

### ❓ 질문 리스트 (총 11단계)

1. **Q1**: 어떤 나라 음식이 먹고 싶나요? (한식/일식/중식/상관없음)
2. **Q2**: 지금 든든한 식사가 하고 싶나요? (식사/간단히)
3. **Q3**: 따끈한 국물이 있는 요리를 원하시나요? (예/아니오/상관없음)
4. **Q4**: 오늘 매운맛이 당기나요? (매우/약간/전혀)
5. **Q5**: 고기가 들어갔으면 좋겠나요? (예/아니오)
6. **Q6**: 차가운 음식도 괜찮나요? (예/아니오/상관없음)
7. **Q7**: 면 요리가 당기나요? (좋음/싫음)
8. **Q8**: 원하는 조리방식은? (구이/찌개탕/볶음/튀김/상관없음)
9. **Q9**: 오늘 식사 예산은? (1만원이하/1만원이상)
10. **Q10**: 지금 분위기는? (혼자/여럿이)
11. **Q11**: 지금 당장 생각나는 느낌은? (고소/칼칼/담백/기름진/신선)
