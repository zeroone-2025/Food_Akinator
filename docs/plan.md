# 📋 제로톤 기획 문서 ([plan.md](http://plan.md/))

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| **프로젝트명** | **푸드네이터 (Food-nator)** |
| **한줄 소개** | 10문장 내외의 질문으로 오늘 당신이 먹고 싶은 한국 음식을 맞히는 AI 아키네이터 |
| **Pain Point** | "오늘 뭐 먹지?"라는 결정 장애로 인해 메뉴 선택에 너무 많은 시간과 에너지를 소비하는 현대인 |

## 2. 타겟 사용자

- **주요 타겟**: 메뉴 결정권이 있지만 선택이 어려운 직장인 및 학생
- **사용자 특성**: 인터랙티브한 재미를 추구하며, 빠른 의사결정 보조 도구가 필요한 사람
- **시장 규모**: 배달 앱 사용자 및 외식 빈도가 높은 2040 세대 전체

## 3. MVP 범위 (2시간 내 구현)

- [x]  **핵심 기능 1: 단계별 필터링 엔진**
    - 15종의 한식 DB와 질문 답변에 따른 가중치/필터링 로직 구현
- [x]  **핵심 기능 2: 가변형 질문 UI**
    - 질문의 중요도에 따라 선택지(1~5개)를 유동적으로 노출
- [x]  **핵심 기능 3: 최종 결과 도출**
    - 10단계 내외의 질문 종료 후 최종 음식 추천 및 이유 설명

## 4. 데이터셋 및 질문 설계

### 🍱 한국 음식 15종 리스트

1. **김치찌개** (국물, 매움, 돼지고기)
2. **비빔밥** (비국물, 건강식, 채소위주)
3. **불고기** (비국물, 달콤, 소고기)
4. **떡볶이** (분식, 매움, 탄수화물)
5. **삼겹살** (구이, 기름짐, 돼지고기)
6. **냉면** (차가움, 면요리, 깔끔)
7. **삼계탕** (보양식, 뜨거움, 닭고기)
8. **된장찌개** (국물, 구수함, 두부/채소)
9. **잡채** (면요리, 달콤/고소, 잔치음식)
10. **제육볶음** (비국물, 매움, 돼지고기)
11. **파전** (기름짐, 밀가루, 비오는날)
12. **육회** (날것, 소고기, 신선)
13. **닭갈비** (볶음, 매움, 닭고기)
14. **칼국수** (국물, 따뜻, 면요리)
15. **족발** (고기, 쫄깃, 야식)

### ❓ 질문 리스트 (총 10단계)

1. **Q1**: 지금 배가 몹시 고파서 든든한 '밥'이 먹고 싶나요? (예/아니오)
2. **Q2**: 따끈한 '국물'이 있는 요리를 원하시나요? (예/아니오/상관없음)
3. **Q3**: 오늘 스트레스를 받아서 '매운맛'이 당기나요? (매우/조금/전혀)
4. **Q4**: 주재료로 '육류(돼지, 소, 닭)'가 들어갔으면 좋겠나요? (예/아니오)
5. **Q5**: 음식이 시원하거나 '차가운' 종류여도 괜찮나요? (예/아니오)
6. **Q6**: 요리 방식은 어떤 게 좋은가요? (구이/찜·탕/볶음/기타)
7. **Q7**: 후루룩 먹기 좋은 '면 요리'를 좋아하시나요? (좋음/싫음)
8. **Q8**: 오늘 예산은 넉넉한 편인가요? (만원 이하/만원 이상)
9. **Q9**: 지금 분위기는 어떤가요? (혼자 빠르게/여럿이 시끌벅적)
10. **Q10**: 지금 당장 생각나는 느낌은? (고소함/칼칼함/담백함/기름짐/신선함)

### 🔍 질문별 추론 로직 (의도 분석)

1. **Q1 (밥/식사 여부)**: 분식(떡볶이), 면류(냉면, 칼국수), 안주류(족발, 육회)와 '식사류'를 크게 분리합니다.
2. **Q2 (국물 유무)**: 찌개류(김치, 된장), 삼계탕, 칼국수 vs 볶음/구이류를 나눕니다.
3. **Q3 (매운맛 정도)**: 김치찌개, 떡볶이, 제육, 닭갈비 vs 불고기, 비빔밥, 삼계탕을 구분합니다.
4. **Q4 (육류 포함)**: 비빔밥, 파전, 된장찌개(채소 위주 시)와 고기 메인 요리를 분리합니다.
5. **Q5 (온도 - 차가움)**: 여기서 '냉면'과 '육회' 같은 특정 메뉴가 강력한 후보로 떠오릅니다.
6. **Q6 (조리 방식 - 구이/볶음/찜)**: 삼겹살(구이) vs 제육(볶음) vs 삼계탕(찜/탕)의 결정적 차이를 만듭니다.
7. **Q7 (면 요리)**: 냉면, 칼국수, 잡채를 필터링합니다.
8. **Q10 (최종 느낌)**: 마지막에 후보가 2~3개 남았을 때 '기름진(삼겹살/족발)' 혹은 '신선한(육회/비빔밥)' 등의 감성적 속성으로 마침표를 찍습니다.
